# Agent operating instructions — canonical workspace

**Canonical repository: https://github.com/sloev/grudgemixes**

This repository is the single active workspace for all three research projects:
1. **Grudge Mixes** — the original pre-1926 grudge / retaliation / revenge recording project.
2. **Insane Music** — the worldwide discography and archival map of music from psychiatric hospitals, prisons, camps, closed communities, and outsider / self-taught contexts.
3. **Soviet Film Music** — research into music, scores, songs, cues, performers, and sound worlds of Soviet cinema.

## Mandatory routing rule for every scheduled or autonomous agent

- Do all new work, edits, research notes, lead tracking, catalogue updates, collaboration logs, manifests, and audio-request tracking in **this repository only**.
- Do not create new work, commits, branches, issues, or pull requests in `sloev/insanemusic` or `sloev/sovietfilm`.
- Treat those two repositories as legacy/reference archives during transition. Read them only when needed to recover context or verify that material has been migrated. If useful material is missing here, report it in this repository's migration/backlog notes; do not resume work in the old repository.
- Never assume that a legacy file has been migrated just because a redirect exists. Verify the corresponding canonical file before relying on it.
- If an agent starts from a scheduled task whose instructions name an old repository, stop and reroute the task here.

## Project boundaries remain distinct

The shared workspace does **not** merge the projects' admission rules, editorial aims, or evidence standards. Before working, identify the project and read its own methodology. Never transfer a rule or inclusion decision from one project to another.

- Grudge Mixes: read `METHODOLOGY.md`, `GROK_HANDOFF.md`, and `TRACK_MAPPING.md`.
- Insane Music: read the Insane Music project methodology and catalogue / archive-request guidance in its project area (or consult the legacy repository if not yet migrated).
- Soviet Film Music: read the Soviet Film Music research method, cue/object distinctions, and audio-collection guidance in its project area (or consult the legacy repository if not yet migrated).

## Two work tracks

1. **Discovery:** find new leads; capture source evidence, original-language terms, exact identifiers, dates, provenance, uncertainty, project fit, and next verification step. Deduplicate before adding.
2. **Enrichment and production:** advance existing leads into evidence-backed records, project-specific catalogues / compendia / mix or cue data, and precise audio retrieval requests for agents that genuinely have download and Google Drive access.

For every task:
1. Read this file, the relevant project methodology, and the latest shared collaboration log.
2. Check existing records and active claims to avoid duplicate work.
3. Claim a bounded task in the shared log before substantial research.
4. Cite sources close to claims; preserve original spellings and uncertainty.
5. Keep research confidence, project admission, audio availability, rights, and retrieval status as separate fields.
6. Agents without Drive/download capability must not claim to have retrieved or verified files.
7. Finish with a dated hand-off listing changed files, evidence, unresolved questions, and the next action.

## Migration caution

The canonical repository is the only place to work going forward, but migration completeness must be verified project by project. Preserve legacy IDs, source links, editorial distinctions, and history. Do not delete, overwrite, or claim completion of material that has not been checked. The owner decides scope, inclusion, rights, and publication.
