# Sovietfilm audio collection queue

**Purpose:** shared hand-off board for turning research into actual audio files in the sovietfilm Google Drive folder. This is a working queue, not a list of files already collected.

**Destination:** https://drive.google.com/drive/folders/1_l7vocHbIfgW0vkzuaNJGFUNSMRIszGQ

## Status definitions

- **RESEARCH LEAD** — plausible musical item/release identified; exact downloadable object or terms not yet checked.
- **READY FOR DRIVE** — exact recording/file and a working lawful download route are identified; terms permit a private research copy.
- **STREAM ONLY** — listening route exists but no permitted file download established.
- **PAID DOWNLOAD ROUTE — OWNER APPROVAL** — a legitimate store advertises a downloadable file, but purchase/territory/terms must be checked and no purchase is authorised by this queue.
- **PERMISSION NEEDED** — download/access requires permission or an account/reading-room process.
- **BROKEN LINK** — expected file or route is unavailable.
- **IDENTITY UNRESOLVED** — item cannot yet be matched confidently to the exact film cue/recording.
- **IN DRIVE — VERIFIED** — Drive-capable agent uploaded the file and reopened/verified it in the destination folder. Only this status counts as collected.

A stream, embedded player, YouTube page, catalogue record, product page or Discogs listing is **not** a downloaded track.

## Agent instructions

### Every research agent
1. Read AGENTS.md, research_method.md, and the latest coop.log.md before claiming work.
2. Add track-level candidates here during research, not only in a prose dossier. Search original-language sources and identify specific cues/songs/themes/releases.
3. For each candidate, resolve the exact recording object (film mix, album master, reconstruction, re-recording, compilation, dub, etc.). Never conflate them.
4. Find and test the actual access route where possible. Record whether it is a direct file download, paid download, stream-only, restricted archive, broken link, or permission route.
5. Add source links and access dates in the relevant research dossier; claim only what was actually checked.
6. Put your name/agent label and task in the Research owner field; append a hand-off to coop.log.md telling Drive-capable agents which entries are ready.
7. If you cannot download because you lack Drive access, still complete the research and mark the candidate accurately. Do not wait for Drive access to contribute.

### Drive-capable agents
1. Check for READY FOR DRIVE entries and take ownership in the table before downloading.
2. Download only from a lawful source whose terms permit the private research copy; do not bypass DRM, access controls or archive restrictions.
3. Upload to the destination folder above, using a descriptive filename that distinguishes original film audio, reconstruction, re-recording or commercial compilation.
4. Reopen/list the uploaded file in Drive and verify it exists. If practical, verify that it plays and is complete.
5. Change status to IN DRIVE — VERIFIED only after verification. Record the exact Drive URL, filename, source URL, format/codec, size, duration and checksum if available.
6. If blocked, leave the candidate in the accurate blocked status and state exactly what is needed next.
