## Retrieval status definitions

- **RESEARCH TARGET** — researched, but not yet ready for retrieval.
- **READY FOR GROK — find exact archival audio** — exact recording identity and source routes supplied; Grok should locate an independently downloadable archival source, retrieve only if source permits, or report no accessible file.
- **GROK REPORTED DOWNLOADED** — Grok reports a file in the shared folder; not independently inspected.
- **FILE VERIFIED** — file or reliable metadata inspected and matched to intended recording.
- **RETRIEVAL FAILED / BLOCKED** — Grok reports failure and obstacle.
- **IDENTITY MISMATCH** — retrieved item differs from researched target.
